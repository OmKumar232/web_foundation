# InAmigos Foundation Website

This is a modern, responsive, and professional website built for the **InAmigos Foundation**. It features a clean design matching the latest NGO website trends, with high-quality sections and smooth animations.

## Tech Stack
- **React 18**: For modular UI.
- **Tailwind CSS**: For high-performance, responsive styling.
- **Framer Motion**: For fluid animations and interactions.
- **Lucide React**: For beautiful, modern iconography.

## Features
- **Responsive Navigation**: Sticky header with mobile-optimized menu.
- **Impact Stats**: Dynamic counters for Volunteers, Projects, and Lives Impacted.
- **Project Showcase**: Card-based project information with read-more capability.
- **Event Management**: List of upcoming events with registration options.
- **Impact Stories**: Heartwarming testimonials from the community.
- **Contact Integration**: Professional contact form and multi-channel support information.
- **Scroll to Top**: Smooth navigation for better user experience.

## How to Run in VS Code
1.  **Clone or Download**: Get the files into your local machine.
2.  **Open Terminal**: Open the project folder in VS Code.
3.  **Install Dependencies**:
    ```bash
    npm install
    ```
4.  **Start Development Server**:
    ```bash
    npm run dev
    ```
5.  **Build for Production**:
    ```bash
    npm run build
    ```

## Files for Upload
The core design logic resides in these 3 files:
- `src/App.tsx`: Layout and Logic.
- `src/index.css`: Styling and Theme.
- `index.html`: Entry Point.
